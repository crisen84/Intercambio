            Publicar en GitHub

            Descarga una página con las listas de deseos de todos para subirla a GitHub Pages. No dice quién le regala a quién ni guarda teléfonos ni correos.

            1. Descarga la página: se llama index.html.
            2. Súbela a un repositorio de GitHub y activa GitHub Pages en su configuración.
            3. En «Enviar por WhatsApp o correo», elige «Un enlace secreto» y pega la dirección de la página. Cada quien verá a quién le regala y su lista completa, con imágenes.

            Cualquiera que tenga la dirección podrá ver las listas.
